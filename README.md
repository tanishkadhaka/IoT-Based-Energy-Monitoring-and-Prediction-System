# IoT-Based-Energy-Monitoring-and-Prediction-System
IoT-based energy monitoring &amp; prediction system using an ESP32 (Wokwi-simulated) with DHT22, PIR &amp; LDR sensors. Random Forest model (R²=0.921) forecasts consumption &amp; Indian slab-tariff costs, visualized on a real-time Flask + Chart.js dashboard with anomaly alerts.
